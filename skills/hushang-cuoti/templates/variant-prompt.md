# 变式生成约束（variant-prompt v1.0）

## 生成 prompt 硬约束（发给当前会话模型）

```
基于错题卡 wa-{id}（知识块 {kp_ids}，断点 "{breakpoint}"，骨架 {key_steps}）生成变式：
1. 原创改编，禁止复制/微改任何真题原题；同知识块、同解题模型、情境换新。
2. 难度锚定：{原难度}±1档，出 3选择题 + 2填空 + 1解答（可按用户要求配比）。
3. 每题附：答案、解题骨架(3-6步)、易错点点名"针对断点X"。
4. 梯度：题1仿做(直接应用骨架)→题3变式(换壳)→解答题逼近原压轴(新定义/复合情境)。
5. 数据自洽：物理化学数值必须算得通、结果落在合理量级（自检：代回原方程）。
6. 若含图：按下方图示规范程序化生成，不许"如图所示"空占位。
```

## 图示生成规范（继承初中版被验证资产，扩科）

| 场景 | 工具 | 备注 |
|---|---|---|
| 数学函数/几何/统计图 | matplotlib（Agg无头，SimHei→系统中文回退由渲染器探测） | dpi=150，宽≤15cm |
| 物理电路图 | schemdraw（不可用则 matplotlib 简化符号，继承初中版电路模板函数） | 电表/滑变/开关标注齐全 |
| 化学装置/流程框图/溶解度曲线 | matplotlib patches / FancyBboxPatch（初中版模板直接复用） | 新增：有机制备装置简化图 |
| 生物遗传系谱/种群曲线 | matplotlib（v1.1 扩科时补模板） | |
| 地理等值线/统计图 | matplotlib（v1.1） | |

图示代码模板存放位置：`scripts/figures/`（可扩展，只放经运行验证过的函数，不放伪代码）。

## 输出与入库

- 生成后写 `output/pending-variants-{date}.md`（每题带 local_id），走 review-gate 流程；
- 通过后 `cuoti.py variant-import --file`（自动带 reviewed 标记）；未过题不入库。
- 卷首注记：本卷由沪上错题基于 {wa-ids} 生成，知识块 {kp_ids}，政策口径 {policy_year}。
