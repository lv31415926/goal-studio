# 科目激活与画像运营（subject-activation v1.0）

## 1. 两种"科目范围"，不要混淆

- **技能建设范围**（v1.0=数学/英语/物理/化学四科精建知识块表）：工程问题，扩科=加 subjects/*.md。
- **学生激活范围**（config.json）：学情问题，由"设置"动词写入。

```json
config.example = {
  "student": "default",
  "grade": "高二",
  "textbook_edition": {"数学":"沪教版2020","英语":"沪教牛津","物理":"沪科技版","化学":"沪科技版"},
  "exam_mode": {"数学":"unified","英语":"unified","物理":"graded","化学":"graded","政治":"pass_only"},
  "targets": {"物理":"B+","化学":"A"},
  "next_exam": {"物理等级考":"2027-05-08(预估)"},
  "push_enabled": false,
  "policy_year": "未核对"
}
```

## 2. 运行时行为差异（对接 grading-policy §3 / schedule-spec §3）

| 激活态 | 排期权重 | 判分严格度 | 画像输出 | 变式 |
|---|---|---|---|---|
| 统考科(unified) | ×1.0 | 标准双条件 | abs分轴 | 找+造全开 |
| 等级科(graded) | ×1.5 | 关键点必查+band成本入报告 | 掉级成本/目标等第差距 | 全开+优先 |
| 合格考轻量(pass_only) | ×0.5 | 只判对错，不建骨架 | 仅合格线风险一行 | 默认关，用户点名才出 |
| 未激活(unlisted) | 不入清单 | — | 不建画像 | 关 |

## 3. 长周期节奏（高一→高三；时点按 2026-10-16 核实组官方口径，见 grading-policy §5）

- 高一：两学期完成物化必修一/二（物理必修三在**高二上**）；合格考不冲刺（高一6月只能报信息技术）。
  统考三科打底；**不开**掉级叙事（选科未定）。未学先练预警在此阶段价值最高。
- 高二：**6月物化合格考首考**（另1月机考补考/高三通道）；下学期选科窗口——报告可附"选科参考"节
  （基于错题簇稳定性，不代做决策，注明赋分竞争"选科=选对手"与物化双选专业覆盖率>96%事实，以当年文件为准）。
- 高三：等级考价值窗口在**5月考试前**——9月起技能进入强介入模式（考前簇自动合并远期唤醒项、
  外语1月首考后触发"两考决策建议"）。
- 选科后未选科目自动降级 pass_only，错题保留但不刷屏。

## 4. 两级画像（学生→学科→知识块）

- profiles.jsonl 每次报告前增量更新：读上一版画像 + 新增错题 → LLM 合并摘要（禁止全量重算；
  摘要失败只出本批统计，画像不动——schedule 兜底）。
- 画像字段：各学科 knowledge-point 薄弱簇 Top5（带 band/abs 成本）、错因六类分布、
  状态机健康度（积压量/销号速率）、近30天趋势一句话。
- **多学生隔离**：student 字段贯穿全部记录；候选池/相似题检索默认只同 student；跨 student 复用
  题目须用户显式开启（修复初中版跨生泄露缺陷）。

## 5. 家长端与多角色

- 周报默认学生版。config.push_enabled + "发给家长"时输出家长版：去情绪化措辞、只保留
  事实+3条可执行建议（如"本周物理电磁感应簇连错2次，建议周末用技能出变式卷20分钟"）。
- 综评材料视角（高三下学期）：`cuoti.py stats --days 120` 可导出"学习过程"数据摘要
  （订正量/销号率/薄弱改进轨迹），供综评"学科特长与学习精神"佐证，标注数据来自本地错题本。
