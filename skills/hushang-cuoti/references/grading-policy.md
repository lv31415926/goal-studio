# 上海高考制度与掉级成本换算（grading-policy v1.2）

## 0. 基准定义（本技能知识系统的"标准"，用户裁决 2026-10-16）

本技能一切知识点、范围、进度、分值口径以以下三层为**唯一标准**，按权威度自高至低：

1. **课程与大纲层**：《普通高中课程方案》与《普通高中课程标准（2017年版2020年修订）》
   （教育部 2020 年印发；等级考命题直接依据——考试院专家点评原文自证 shmeea.edu.cn/page/02100/
   20250506/19309.html）+《上海市普通高中课程实施方案》（**沪教委基〔2021〕35号**，2021秋起执行，
   shanghai.gov.cn 公报原文）——决定"考什么范围、何时学完必修"。
2. **教材层（2026 高一在用）**：沪教版/沪科技版 **2020版**教材（2026秋高中目录与2025准用号一致=不换代，
   沪教委基〔2026〕18号公报）逐册章目录——决定"学生这学期学到哪"（学期×册次矩阵的数据源，§5）。
3. **年度考试文件层**：当年《学业水平考试实施细则》《等级考命题要求》《春考/综评/强基办法》——
   决定"今年怎么考"（分值/时间/比例），逐年「更新政策」核对，未核对前 policy_year="未核对"。

冲突裁决：层1>层2>层3 仅指"范围与进度"；**分值与考试安排以层3当年文件为准**。
知识点→课标条款的逐条映射见 `references/subjects/*.md` 各表"课标映射"节（v1.3 起）。

**课标一手文本获取口径（2026-10-16 取证）**：教育部教材〔2020〕3号通知附件 zip
（moe.gov.cn/srcsite/A26/s8001/202006/W020200603315372317586.zip，22份PDF带文字层）为唯一一手源；
通知明言"数学/英语/物理/化学修订**仅涉及前言**"→ 四科正文=2017年版，映射可直接引 2017 全文。
物理结构=类别→模块→主题→分条（必修3模块9主题42条，**无'系列'层**）；化学必修**不划模块**设5主题
（分条自带标题，映射键最佳）；数学=主题→单元→条目→细目；英语=课程内容六要素+学业质量三水平
（必修无独立学业要求节，达成=水平一）。

**学段时点口径（防误引）**：《上海市普通高中课程实施方案》（沪教委基〔2021〕35号）**没有**"必修最迟
何时学完"的明文条款（原文仅"控制高一必修并开科目数量""统筹安排各年级"——学段划分下放学校）；
"六科必修须在高二第二学期末前完成"是**由沪教委规〔2021〕3号考试安排表（随教随考随清：高二下期末
六科合格考/高三上期末语数外合格考/高三下等级考）反推的推断**，引用时必须带"推断"标签。
35号文可实证的硬数字：学年学分制（1学分=18课时，毕业144=必修88+选必≥42+选修≥14）、
周课时38节/1575分钟、课程计划示例（按学期学分：数学2|3|3|3|3、外语3|3|3|3|2、物理2|2|2|2|4、
化学1|2|1|3|3）——**示例不区分必修/选必**，不能据其断定必修完成时点；单科必修完成时点以
教材册次进度（层2，教参"使用时间"已实证）+学校实际为准。志愿服务上海口径"三年不少于60课时"
（国家40小时，沪版加码，综评要用）。

## 1. 制度骨架（2026年口径核实）

- 总分 **660** = 语文150 + 数学150 + 外语150（统考原始分）+ 3门等级考各70。
- **"3+3"**：政史地物化生六选三，**高考报名时锁定，仅考1次，不可换科**；考试在高三5月上旬，60分钟/科，卷面100。
- **等级赋分**：五等十一级（A+≈5%、A/B+/B/B-/C+/C/C-/D+各≈10%、D/E≈15%），A+=70、级差3分、E=40保底。
  同一卷面分因群体不同可差6-9分——错题管理是**位次逻辑**，不是绝对分逻辑。
- **外语一年两考**（1月春考卷+6月秋考卷）取较高分；笔试+听说测试（人机对话）。
- **合格考**10科合格/不合格，合格永久有效；须先合格方可报该科等级考。语数外合格考仅限高三，可用高考成绩替代。
- 升学通道：春考（文化450+院校自测150）/ 综评批（高考85%+校测15%）/ 强基（高考≥85%+校测≤15%，部分校出分前校测）；2024起多数理工专业要求**物化双选**。
- 与中考差异：中考750原始分绝对分逻辑；高考小三门百分位赋分。

## 2. 掉级成本换算规则（技能内计算口径）

设学生在等级考科目目标等第为 T（如 B+）：

1. **掉级成本 points 口径**（写入错题卡 `score_axis.points`，数值）：经验档 掉半级=1.5、
   掉一级=3.0；统考科目用 `type:abs, points:卷面扣分`。此为 v1 经验值，报告页脚须注明"经验换算仅供参考"。
2. **错题簇优先公式**：唯一权威源是 `schedule-spec.md §3`（w_等级考=×1.5，含 band bonus），
   本文件不再另写公式，避免两处口径漂移。
3. D/E 边缘（保底40分逻辑）学生：不适用"冲A"叙事，切换为"守住合格+卷面基础题全对"目标函数。
4. **外语两考博弈**：1月首考后生成"是否弃6月再考"建议——依据两次成绩差、听说短板、6月主科复习负荷。

- 春考院校数/综评院校名单/强基校测模式（逐年调整）
